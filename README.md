# AI-Enabled Contract Lifecycle Management

Interactive front-end prototype implemented from the Figma design node `272:4967`.

## Run locally

Open `index.html` directly, or start a local server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Prototype interactions

- Collapse/open the sidebar
- Search and select recent conversations
- Navigate between primary sections
- Start a new chat
- Attach contract documents
- Use suggested prompts
- Send a request and view the simulated “AI proposes, human decides” response
- Select activity metrics

The layout is responsive for desktop, tablet, and mobile widths.
